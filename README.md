## 👋 **백엔드 개발자 조희제**

**① 상대방의 어려움을 그냥 지나치지 않고, 함께 고민합니다.**

데브코스 Wibby 프로젝트에서 코드 리뷰를 담당하며 팀원들의 코드를 검토하던 중, 여러 팀원이 객체지향 설계의 핵심 개념인 추상화를 이해하고 <br>
적용하는 데 어려움을 겪고 있다는 점을 발견했습니다. 단순히 수정 사항을 전달하는 데 그치지 않고 실제 코드 사례를 중심으로 함께 고민하는 시간을 마련했고, 팀원들로부터 추상화가 이렇게 쉬운 건지 몰랐어요라는 피드백을 받았습니다.

**② 기술에 대한 탐구를 즐깁니다.**

새로운 기술을 단순히 사용하는 데 그치지 않고, 동작 원리와 이유를 이해하려 노력합니다. 데브코스에서도 궁금한 점을 적극적으로 질문하며 학습했고, 이러한 태도를 인정받아 교육생 투표에서 최다 득표로 ‘질문왕’에 선정되었습니다.
